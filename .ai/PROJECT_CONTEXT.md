# PROJECT_CONTEXT.md

# AI Job Automation Platform

## Project Vision

Build a production-grade AI-powered workflow automation platform that helps users automate job discovery, resume optimization, application workflows, interview preparation, and notification systems using modern AI models and workflow orchestration.

The platform should resemble a real SaaS product with scalable backend infrastructure, AI orchestration pipelines, event-driven processing, queue workers, observability, and DevOps automation.

The system should support both cloud-hosted AI APIs and local AI models.

---

# Core Goals

## Primary Goals

* Automate job discovery across multiple platforms
* Optimize resumes using AI
* Generate customized cover letters
* Automate application workflows
* Track applications and statuses
* Send notifications and reminders
* Build reusable workflow pipelines
* Support multi-model AI orchestration
